Acesso

Para salvar e iniciar buscas por aqui, esta página usa um token do GitHub, guardado só neste aparelho.
Como criar o token
  1. No GitHub: foto do perfil → Settings → Developer settings.
  2. Personal access tokens → Fine-grained tokens → Generate new token.
  3. Repository access: Only select repositories → cacador-passagens.
  4. Permissions: Contents = Read and write; Actions = Read and write.
  5. Gere, copie e cole acima. Ele funciona como senha: não mostre a ninguém.
